Energy consumption forecasting

A leakage-safe XGBoost system that forecasts PJM East electricity demand 24 hours ahead from historical load, calendar signals, and weather variables.

The operational problem

Grid operators must anticipate hourly electricity demand to balance supply, minimize waste, and preserve reliability. This project predicts the next day’s PJM East load for operational planning.

Data & preparation

The primary source is PJM East hourly consumption from 2002–2018. Timestamps are sorted, duplicates resolved, and short gaps time-interpolated before feature generation.

Weather integration includes temperature, humidity, wind speed, pressure, and cloud cover. The demonstrator uses a clearly disclosed deterministic climatology proxy because historical API access is subscription-dependent.

Forecast design

At origin time t, the model predicts PJME_MW at t + 24h. Lag and rolling variables use information available at or before t; calendar and weather inputs describe the predicted time.

Feature families

  • Calendar: hour, weekday, month, quarter, year
  • Cyclical hour and weekday encodings
  • Lags: 1–72 hours plus weekly and biweekly history
  • 24-hour rolling mean and standard deviation
  • Five weather measures

Model configuration

n_estimators=900 · learning_rate=0.035 · max_depth=7

Early stopping uses a chronological holdout. Test targets begin on 2017-01-01, preventing look-ahead leakage.

Evaluation integrity: a valid day-ahead evaluation cannot use observed future load inside the forecast horizon. This project avoids that shortcut.
